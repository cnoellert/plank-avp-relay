PLANK AVP Relay Setup: USB Ethernet settings for the dedicated relay box.

- The product is now PLANK AVP Relay. The Linux package migration preserves saved identity and pairings.
- The new Network tab separates editable Network mode from read-only Connection status. Choose Bridge (default) or Router, then Apply changes.
- Ethernet and USB indicators are status labels, not configuration switches. USB status reflects the controller connection, not just a running service.
- Mode changes use the existing authorized headset connection. Bluetooth control is preferred; the app reconnects and confirms the saved result if the network changes.
- The relay completes an accepted mode change independently of the app. Tablet bonds and headset authorization are retained.
- USB Ethernet is provided only while the wired Ethernet link is present. Internet access is not required, and traffic is never forwarded through relay Wi-Fi.

Requires relay package 0.4.0 for network settings. USB gadget operation is enabled automatically on the supported Armbian NanoPi Zero2 appliance; other hosts report its availability.

Please test both modes, cable removal/restoration, and app reconnection after Apply. Confirm the two status rows look informational and cannot be toggled. Physical USB/AVP qualification and installation on the currently unavailable relay remain pending.
